Group03 – Application requirements (Hands-on Assignment 1)

1. Application overview

Madrid Air Quality Stations Explorer is a web application that lets users explore the 24 stations of the air quality surveillance network of the city of Madrid. Users can see where each station is, which type of station it is, and which pollutants it measures, and they can filter and search the stations.

The application is built on top of the dataset selected in datasetRequirements.html (Calidad del aire. Estaciones de control, Ayuntamiento de Madrid, CC BY 4.0). In later assignments the data will be transformed into RDF, linked with other datasets and published, and the application will query that RDF data.

2. Users

UserNeed
CitizenFind the stations closest to the place where they live or work and know what each station measures.
Student or researcherCompare station types and pollutants, and obtain structured data about the network.
City technicianCheck at a glance which stations measure each pollutant and where the network has gaps.

4. Non-functional requirements

  • Licensing: the attribution required by CC BY 4.0 must be visible (FR8).
  • Usability: the filters must be usable without technical knowledge, and the map and filters must work on desktop and on mobile screens.
  • Performance: with only 24 stations, filtering and searching should feel instantaneous.
  • Data access: in later assignments the application will read the data from an RDF dataset through SPARQL queries instead of from the CSV file.
  • Data quality: stations with empty street fields (for example Juan Carlos I) must be displayed without errors.

5. Questions the application must answer

These questions can be answered from the selected dataset and will be used later as SPARQL queries.

  1. Which stations measure PM2.5?
  2. Which stations are urban traffic stations?
  3. Which stations are located above 700 metres?
  4. Which pollutants does a given station measure?
  5. Which stations started operating after 2009?

6. User interface description

The application has three views. The map view is the main screen: a filter panel on the left (search box, station type, pollutants) and the map on the right, with one coloured marker per station (red for urban traffic, blue for urban background, green for suburban) and a legend. Pressing a marker opens a small station card with the main data and a button to open the full detail. The list view shows the same stations in a table that can be sorted. A footer with the data source and the license is always visible.
