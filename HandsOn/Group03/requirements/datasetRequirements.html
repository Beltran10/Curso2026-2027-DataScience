1. Selected dataset

TitleCalidad del aire. Estaciones de control (Air quality. Monitoring stations)
PublisherAyuntamiento de Madrid – Dirección General de Sostenibilidad y Control Ambiental
PortalMadrid City Council open data portal (datos.madrid.es)
Filecsv/212629-0-estaciones-control-aire-csv.csv
DescriptionThe air quality surveillance network is made up of 24 automatic remote stations. The dataset describes each station: identifier, address, coordinates, altitude, station type and the pollutants it measures.
Portal metadataCategory: Environment (Medio ambiente). First published: 9 April 2015. Last updated: 11 June 2026. Available as XLS, CSV, PDF and GEO.

3. Linkable entities

Entities in the selected dataset that can be linked with entities in other datasets

  • Stations (CODIGO, ESTACION): can be linked by coordinates to geographic datasets such as OpenStreetMap or GeoNames, and by name to Wikidata items of the places where they are located (for example Plaza de España, Parque del Retiro, Casa de Campo, Plaza Castilla).
  • Streets (VIA_CLASE, VIA_NOMBRE, COD_VIA): can be linked with the street directory of the municipality.
  • Municipality of Madrid (code prefix 28079): can be linked with Wikidata, DBpedia and GeoNames.
  • Pollutants (NO2, SO2, CO, PM10, PM2.5, O3, BTX): can be linked with Wikidata items for each chemical or particle type.
  • Station types (UT, UF, S): can be mapped to a controlled vocabulary of station classification (traffic, background, suburban).

Entities in other datasets that can be linked with entities in the selected dataset

  • Hourly air quality measurements of the same portal, which identify the station by code. We have seen its columns but not yet checked that the codes match, so this link is a candidate.
  • Wikidata, DBpedia and GeoNames entities for Madrid and for the places where the stations are located.
  • Other city datasets with coordinates (for example green areas and trees) can be related to the stations by proximity. This is not verified yet.

5. Data quality notes

  • Coordinates appear in three formats: degrees-minutes-seconds (with two different quoting styles, for example in Parque del Retiro and Juan Carlos I), projected ETRS89 with a decimal comma, and decimal degrees. We will use the decimal degrees to generate RDF.
  • The pollutant columns (NO2, SO2, CO, PM10, PM2_5, O3, BTX) contain X or are empty, instead of boolean values.
  • Some street fields are empty: the station Juan Carlos I has no street class, particle or name (and its street code is 1111); Plaza Elíptica has no street particle.
  • The address field mixes free text and street intersections, so it should not be used as the only key for linking.
