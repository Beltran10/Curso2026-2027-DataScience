BiciMAD Explorer - Application Requirements

1. Application Description

BiciMAD Explorer is a web application designed to help users find and explore public bicycle stations in Madrid. The application uses open data published by the Madrid City Council.

Its main objective is to promote sustainable urban mobility by making information about BiciMAD stations easier to access.

2. Target Users

The application is intended for Madrid residents, students, tourists and anyone interested in using the BiciMAD public bicycle-sharing service.

3. Application Functionalities

3.1. Interactive Map

Users will be able to visualize BiciMAD stations on an interactive map of Madrid. Each station will be represented by a marker based on its geographical coordinates.

3.2. Station Information

By selecting a station, users will be able to view its name, address, total capacity and service status.

3.3. Search Functionality

Users will be able to search for stations by their name, number or address.

3.4. Station Filtering

The application will allow users to filter stations according to their service status. For example, users will be able to display only stations marked as IN_SERVICE.

3.5. Station List

In addition to the map, the application will provide a list of stations showing their names, addresses and capacities.

5. Data Used by the Application

The application will use the BiciMAD stations dataset published by the Madrid City Council. The main fields used will be:

  • Name: station name.
  • number: station identifier.
  • Address: station address.
  • TotalBases: total number of bicycle docks.
  • State: station service status.
  • POINT_X and POINT_Y: geographical coordinates.

The dataset provides station information, but it does not guarantee real-time bicycle availability. Therefore, the application will not display the number of bicycles currently available at each station.

6. Expected Benefits

BiciMAD Explorer will make it easier to locate bicycle stations, explore their characteristics and identify stations that are in service.

The application aims to improve access to public mobility information and encourage sustainable transportation in Madrid.
