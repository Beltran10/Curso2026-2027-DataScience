BiciMAD Explorer - Dataset Requirements

1. Dataset Description

The selected dataset contains information about BiciMAD, the public bicycle-sharing system in Madrid. It is published by the Madrid City Council Open Data Portal.

The CSV file contains 631 records and 12 columns, including station identifiers, names, addresses, geographical coordinates, station capacity and status.

Dataset source: BiciMAD Stations - Madrid Open Data Portal

2. Dataset Requirements

R1. Smart City Domain

The dataset belongs to the Smart Cities domain, specifically sustainable urban mobility. BiciMAD promotes bicycle transportation and provides an alternative to private motor vehicles in Madrid.

R2. CSV Format

The dataset is available in CSV format. The selected file is named bikestationbicimad_csv.csv and contains 631 records and 12 columns.

R3. Open License

The dataset is published under the Creative Commons Attribution 4.0 International (CC BY 4.0) license. This license allows the data to be shared and adapted, provided that appropriate attribution is given.

R4. Linking with Real-World Entities

The dataset contains geographical information that can be linked to other real-world entities. The Address, POINT_X and POINT_Y fields allow BiciMAD stations to be associated with streets, neighborhoods and districts in Madrid.

R5. Documentation (Optional)

The Madrid Open Data Portal provides documentation describing the content and structure of the dataset. Therefore, this optional requirement is satisfied.

R6. Multiple Data Sources (Optional)

Currently, the project uses one dataset provided by the Madrid City Council Open Data Portal. In future stages, additional datasets containing information about Madrid's districts or streets could be incorporated.

3. Possible Links with Other Datasets

The BiciMAD dataset contains several fields that could be used to establish links with other datasets.

  • Address: could be linked to street information from other Madrid datasets.
  • POINT_X and POINT_Y: could be used to associate stations with geographical entities such as neighborhoods and districts.
  • Name and number: could help identify the same stations in other BiciMAD-related datasets.

For example, a dataset containing Madrid's district boundaries could be used to determine which district each BiciMAD station belongs to. The district entities could then be linked to the stations using their geographical coordinates.

4. Conclusion

The selected BiciMAD dataset satisfies the four mandatory requirements (R1-R4) and the optional documentation requirement (R5). The multiple data sources requirement (R6) is not currently satisfied, but additional datasets could be incorporated in future stages.

This dataset is suitable for the BiciMAD Explorer project because it provides information about bicycle stations and their geographical locations in Madrid.
