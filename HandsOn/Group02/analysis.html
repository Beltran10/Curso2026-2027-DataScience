BiciMAD Dataset Analysis

1. Introduction

This dataset contains information about BiciMAD stations in Madrid. Within this dataset, we can find different types of information related to the operation of BiciMAD in Madrid, such as station locations, coordinates, and whether the stations are available or unavailable. The dataset was obtained from the Madrid City Council Open Data Portal.

2. Dataset Structure

The dataset contains 631 records and 12 columns. Each row represents a BiciMAD station. Each column contains a characteristic of the station, such as its name, address, or capacity.

Column Description Data Type
OBJECTID Identifier of each record Integer
Activate Indicates if the station is activated Integer
Address Address of the BiciMAD station String
PosicionSTR Geographical position of the station in text format String
Ligth Numeric indicator related to the station Integer
Name Name of the BiciMAD station String
NoAvailable Indicates if the station is unavailable Integer
number Identification number of the station Integer
TotalBases Total number of bicycle docking spaces Integer
State State recorded for the station String
POINT_X Geographical X coordinate of the station Decimal
POINT_Y Geographical Y coordinate of the station Decimal

3. Data Analysis

3.1. Station Capacity

The 'TotalBases' column indicates how many docking points each station has. According to the data, the minimum capacity is 0, the maximum is 43, the mean is 23.68, and the most frequent value (mode) is 23. There are 2 stations with a capacity of 0. The number of docking points varies from one station to another.

3.2. Station Status

The 'State' column indicates the status of each BiciMAD station. Regarding the stations, we can state that 626 are in service (99.2%), 3 are not in service, one has reached the end of its useful life, and another one is planned.

3.3. Other Indicators

The 'Activate' and 'NoAvailable' columns provide additional information about the stations. Regarding the 'Activate' column, 629 stations have a value of 1, while only 2 have a value of 0. In the 'NoAvailable' column, 626 stations have a value of 0 and 5 have a value of 1. Therefore, most stations have 'Activate' set to 1 and 'NoAvailable' set to 0.

3.4. Data Quality

Regarding the quality of the dataset, it contains 631 records and 12 columns. According to our analysis, there are no missing values or completely duplicated records. However, we found 2 stations with a capacity of 0, which could be interesting to review.
